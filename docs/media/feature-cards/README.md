# RestockOS feature cards

Eight original 1080×1350 cards, inspired by the supplied editorial screenshot references. The author handle, screenshots and text from those examples are not reused.

The app images are actual browser captures from the isolated seeded recording environment. Lime outlines, chapter headings and feature callouts are editorial annotations. Source screenshots are included under sources/ for reproduction; no credentials or wallet approvals were recorded. Treasury is historical verified Testnet evidence, not a result of the displayed sandbox run. Supplier quotations use the deterministic demo adapter.

Use 01-restockos, 03-inventory, 04-suppliers and 07-treasury as a four-image alternative to the video. The complete series can be shared across two posts with four images each. Keep the original PNGs for upload; the contact sheet is a preview only.

Build: node scripts/render-feature-cards.mjs
Source directory override: SCREENSHOT_DIR=/path/to/captures (files named dashboard-preview.png, inventory-preview.png, quotes-preview.png, agent-preview.png, orders-preview.png, paid-preview.png, admin-preview.png).
The script can reuse the archived sources/ if the temporary recording directory is gone.

Visuals use original vector geometry and Lucide React icons; all typography, outlines, labels and screenshot framing are composed in SVG. These are not fabricated UI mockups. Font rendering uses locally available Arial and Georgia. The background is a dimmed copy of the app screenshot with a native gradient/grid, not a third-party photograph.

The manifest contains upload alt text. index.html is a local gallery. The ZIP contains the eight upload PNGs, alt text and this README.
